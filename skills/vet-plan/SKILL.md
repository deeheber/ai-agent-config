---
name: vet-plan
description: Critically review the current plan or proposal - correctness, problem fit, over-engineering - validating claims with tools
---

Critically review your current plan/proposal:

1. Is it correct - will it actually work? Validate every claim with tools (read the code, run checks). Do not assume.
2. Does it solve the stated problem, fully?
3. Is it over-engineered? We don't want that - flag anything that can be cut or simplified.

If you find problems, correct the plan and say what changed. If it holds up, say why you're confident.
